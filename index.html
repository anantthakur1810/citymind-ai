Connect real traffic data

Optional API

For real road-flow measurements, configure a TomTom Traffic API key in the local backend. The browser never receives the secret key. Without it, traffic values and risk markers remain clearly labelled illustrative examples.

Get an API key from TomTom Developer Portal, then set TOMTOM_API_KEY in the .env file. This app includes a backend endpoint for the integration.

How CITYMIND prioritizes

Explainable prototype logic
  1. Detect: ingest measured traffic flow where the API is configured; weather is fetched live from Open-Meteo.
  2. Score: when observed and free-flow speeds are available, calculate speed loss = 1 − observed/free-flow speed. The score is an indicator, not a trained prediction model.
  3. Prioritize: sort by the score and show the most urgent segments first.
  4. Act: suggest investigation or traffic management review. No physical traffic lights or public infrastructure are controlled.
